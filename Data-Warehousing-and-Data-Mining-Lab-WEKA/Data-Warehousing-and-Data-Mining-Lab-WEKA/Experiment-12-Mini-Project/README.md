# Experiment 12: Mini-Project — Data Mining on a Real-World Dataset

## Aim
To apply one data mining technique to a real-world dataset and present findings.

## Choose one track
- **Classification:** choose a labeled public dataset; use Naïve Bayes, J48, or IBk.
- **Clustering:** choose numeric features; use SimpleKMeans or HierarchicalClusterer.
- **Association rules:** prepare transaction data; use Apriori or an approved FP-Growth implementation.

## Suggested report structure
1. Project title and problem statement
2. Dataset source, license, number of instances/attributes, and target (if any)
3. Data cleaning and preprocessing decisions
4. Algorithm and parameter settings
5. Evaluation method and metrics (if classification)
6. Results from the actual WEKA run, with screenshots
7. Interpretation, limitations, and conclusion
8. References and dataset citation

## Workflow
1. Select and cite a dataset from a reputable public source (for example, UCI Machine Learning Repository or a government open-data portal).
2. Open the dataset in WEKA and inspect attribute types and missing values.
3. Preprocess only as justified; record every filter and option.
4. Run the chosen algorithm and save the output.
5. For classification, use an appropriate holdout or cross-validation scheme and report confusion matrix, accuracy, precision, and recall.
6. Interpret findings without claiming causation from association or clusters.
7. Add screenshots and write the conclusion based on the results actually observed.
