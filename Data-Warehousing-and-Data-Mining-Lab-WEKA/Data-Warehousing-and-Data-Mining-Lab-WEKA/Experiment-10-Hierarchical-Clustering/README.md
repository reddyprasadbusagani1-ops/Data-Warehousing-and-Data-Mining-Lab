# Experiment 10: Hierarchical Clustering and Dendrogram

## Aim
To perform hierarchical clustering and visualize a dendrogram.

## Dataset
Use `points.arff`.

## Procedure
1. Load `points.arff` in WEKA Explorer.
2. Open **Cluster → Choose → HierarchicalClusterer**.
3. Set the number of clusters and linkage method supported by your version.
4. Click **Start** and inspect the cluster output.
5. WEKA's built-in HierarchicalClusterer does not provide a dendrogram visualization in every version. If your version lacks a dendrogram option, export the small numeric dataset and use an instructor-approved visualization tool (such as R or Python) to draw the dendrogram. Clearly identify which tool produced the diagram.
6. Record the selected distance and linkage settings.

## Result
Hierarchical clustering groups similar observations. Attach the cluster output and a dendrogram generated using the approved tool.
